# Code of Conduct

This project follows the spirit of the game: be kind, be patient, and leave things better than you found them.

## Our standards

- Be welcoming and respectful to everyone, whatever their experience, background or identity.
- Give and receive feedback gracefully; critique code, not people.
- No harassment, insults, sexualised content, or publishing others' private information.

## Enforcement

Report unacceptable behaviour privately to the maintainer via the contact on their GitHub profile. Reports are kept confidential. Maintainers may remove comments, commits or contributions that break this code, and may ban repeat offenders.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
